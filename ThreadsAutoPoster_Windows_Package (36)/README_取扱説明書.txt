【重要：起動しない場合の原因特定・自己診断システムについて】
----------------------------------------------------------------
万一「ThreadsAutoPoster.exe」や「start_gui.bat」が起動しない場合は、
フォルダ内の 【🔍原因診断と修復.bat】 をダブルクリックしてください！

● 自動診断・修復ツールができること：
  1. PC内のPython環境を徹底走査（Microsoft Storeの空スタブを自動検知・除外）
  2. GUIライブラリ（tkinter）、Excelライブラリ（openpyxl）、Playwrightを動作テスト
  3. 「startup_log.txt」を解析してどこで止まったか画面上に日本語で表示
  4. メニュー [1] を押すだけで、不足コンポーネントを全自動修復

● 起動ログファイルについて：
  ・startup_log.txt : ThreadsAutoPoster.exe や Python が起動時に自動出力するログです。
  ・crash_log.txt   : 万一プログラムが途中でクラッシュした場合に詳細なエラーを記録します。
  ・診断レポート.txt : 診断バッチ実行時に生成される総合チェックシートです。

【使い方 1: 「ThreadsAutoPoster.exe」で直接起動】
----------------------------------------------------------------
1. ダウンロードしたZIPを必ず「すべて展開（解凍）」します。
2. 解凍後のフォルダ内にある「ThreadsAutoPoster.exe」をダブルクリック！
   ※自動で環境を探し、startup_log.txt を記録しながらGUIを安全起動します。
   ※もし起動しない場合は、後述の「🔍原因診断と修復.bat」をお試しください。

----------------------------------------------------------------
【使い方 2: 「ThreadsAutoPoster.vbs」で起動（Windows 11 おすすめ）】
----------------------------------------------------------------
Windows 11 の「スマート アプリ コントロール」が有効な環境では、未署名の .exe は
ブロックされる仕様になっています。
その場合、同梱の「ThreadsAutoPoster.vbs」をダブルクリックしてください！
→ Microsoft公式の wscript.exe 経由で動くため、スマートコントロールに引っかかる
   ことなく、黒いコンソール画面も出ずに直接GUI画面が即座に起動します！

----------------------------------------------------------------
【使い方 3: 「start_gui.bat」で起動】
----------------------------------------------------------------
1. このZIPファイルをすべて解凍（すべて展開）します。
2. 「start_gui.bat」をダブルクリックします！
   ※万一のエラー時にもウィンドウが閉じずにログを確認できる保持機構を搭載しました。
   → 初回のみ自動で必要なライブラリを確認・インストールし、
     そのままGUI画面が起動します（EXE化の待ち時間不要！）。
   ※Python未導入のPCの場合は、同梱の「0_他のPCでもすぐ動く環境作成.bat」を
     ダブルクリックすると全自動で環境構築が完了します。
----------------------------------------------------------------
1. このZIPファイルをすべて解凍（展開）し、任意のフォルダに置きます。
2. 「build_exe.bat」をダブルクリックして実行します。
   → .NET Framework標準コンパイラで「ThreadsAutoPoster.exe」を自動生成します。
3. 完了後、「dist\ThreadsAutoPoster\」フォルダ内に「ThreadsAutoPoster.exe」と全ファイルが完成します！
4. その中にある「ThreadsAutoPoster.exe」をダブルクリックで起動します！

----------------------------------------------------------------
【使い方 3: 他のPCでも使いたい場合（配布・移行）】
----------------------------------------------------------------
1. 生成された「dist\ThreadsAutoPoster」フォルダ（または解凍フォルダ一式）を
   丸ごとUSBメモリやクラウド（Googleドライブ/OneDrive等）で別のPCへコピーします。
2. 別のPCで初めて動かす時は、フォルダ内の
   「0_他のPCでもすぐ動く環境作成.bat」をダブルクリック！
   → 必要なPythonやPlaywrightブラウザが自動導入されます。
3. あとは「ThreadsAutoPoster.exe」（または「start_gui.bat」）を起動するだけで
   同じ設定・Cookieセッションで即座に自動投稿できます！

【超便利！Authトークン (sessionid) による自動ログイン方法】
----------------------------------------------------------------
毎回手動でログインしたくない場合、「sessionid」Cookieを「アカウント情報.xlsx」の
「auth_token」列に貼り付けるだけで、起動した瞬間からログイン済みとして自動投稿できます！
（※従来の「アカウント名」「Authトークン_sessionid」の列名でも自動判定されます）

[sessionidの取得方法 (たったの30秒)]:
1. 通常のGoogle ChromeでThreads (https://www.threads.net/) を開き、ログインします。
2. キーボードの「F12」キーを押してデベロッパーツールを開きます。
3. 上部タブの「Application（アプリケーション）」をクリックします。
   (見当たらない場合は「>>」をクリックして選択)
4. 左メニュー「Cookies」の中の「https://www.threads.net」をクリックします。
5. リストにある「sessionid」の値をコピーします。
6. 「アカウント情報.xlsx」の「auth_token」列に貼り付ければ完了です！

----------------------------------------------------------------
【完全自動！エクセルの sessionid だけでログインできます】
----------------------------------------------------------------
「アカウント情報.xlsx」の「auth_token」列に取得した sessionid を貼り付けて
「自動投稿を開始」を押すだけで、完全自動でログインして投稿が始まります！

※Threadsの画面で「Threadsでもっと発信しよう」や「Instagramでログイン」等の
　確認画面が表示された場合でも、スクリプトが0.5秒で自動クリックして認証を突破します。
　ユーザー様が手動でブラウザをクリックする必要はありません。

  (または python threads_auto_poster_cli.py)

【Excelファイルの編集方法】
----------------------------------------------------------------
●「アカウント情報.xlsx」
  ・アカウントID : アカウントの識別名（これに対応する <アカウントID>.xlsx が読み込まれます）。
  ・auth_token  : ブラウザから取得したsessionid。これだけでパスワード不要で即座にログイン可能！
  ※Chromeプロファイル保存パス、投稿間隔、投稿モードは削除され、
    各アカウントごとの「<アカウントID>.xlsx」の設定シート側からすべて読み込む仕様になっています。

●「threads_main_account.xlsx」
  【シート1: 設定】
  ・ツイート間隔 (ポスト間隔) : 投稿ごとの待機時間を指定します。
      例: 120 分 〜 360 分（指定範囲の中から毎回ランダムで待機し、アカウントBANを強力防止）
  ・ツイート実行時間 (ポスト実行時間) : 実行する時間帯を指定します。
      例: 0:00 〜 0:00（終日・24時間いつでも実行）または 9:00 〜 22:00
  ・モード :
      0 = 上から順（上から順番に投稿）
      1 = ランダム（未投稿リストからランダム順序で投稿）
  ・Chromeプロファイル保存パス :
      ログインセッションを保存するフォルダ（空欄時は自動で chrome_profiles/<アカウントID> を使用）

  【シート2: 投稿リスト】
  ・ID : 投稿管理ID（1, 2, 3...）
  ・ポスト文章 : 最大500文字以内でThreads投稿文を記入します。（本文中の image2.png も自動検知）
  ・画像ファイルパス : 設定セルに添付画像名（例: image.png や ./images/photo.png）を記入。
  ・ステータス : 「未投稿」の行が対象になります。
    投稿が成功すると、スクリプトが自動で「投稿完了」と「投稿完了日時」を書き込んで上書き保存します。
