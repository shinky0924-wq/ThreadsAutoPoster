# Threads AutoPoster Studio (Web Edition)

Meta Threads 自動投稿システム・マルチアカウント管理、投稿スケジュール、Excel入出力、日常挨拶枠、BAN防止ステルス機能完備のWebダッシュボードです。

## 主な機能

1. **マルチアカウント & セッション管理**
   - 複数アカウントの同時管理（`sll15802`, `jhtwj2`, `wqlopakpskapkoq` 等）
   - `auth_token (sessionid)` によるパスワード不要の自動ログイン
   - sessionidからの `ds_user_id`（ユーザーID）自動抽出・判定
   - アカウントごとの待機間隔（分）、実行時間帯、投稿モード（上から順 / ランダム）の個別設定

2. **投稿リスト管理 & Excel入出力**
   - 投稿文章（最大500文字、文字数カウンター付き）
   - 画像添付の自動検知（`image.png`, `image2.png`, URL等）
   - トピック / カテゴリ分類
   - **Excelダウンロード / インポート**: `sll15802.xlsx` や `アカウント情報.xlsx` のインポートおよび最新状態でのエクスポート

3. **6大マスター機能（BAN防止 & 高速化）**
   - 🔁 **無限ループ投稿**: 全ポスト完了後に自動で『未投稿』にリセットして最初から周回
   - 🪟 **【提案1】1窓・順番交代ローテーション**: 複数アカウントを1窓ずつ交互に切り替えメモリ節約
   - ⚡ **【提案2】画像・動画通信ブロック**: タイムライン画像・動画・リールを遮断（負荷50〜70%削減）
   - 🕵️‍♂️ **【新機能1】ステルス巡回**: 投稿前におすすめタイムラインを自然に閲覧し人間らしい行動を模倣
   - 🧹 **【新機能2】自動プロファイル初期化**: 警告検知時にCookie/指紋を安全リセット
   - 🎯 **【新機能3】トピックA/Bテスト**: 指定トピックを投稿ごとに均等ローテーション

4. **日常つぶやき・あいさつ枠**
   - 朝枠(7:00-9:00)、昼枠(12:00-13:30)、夜枠(21:00-23:30)の日常枠優先投稿
   - `{おはよう|こんにちは}` のスピンタックス自動展開
   - `{today}` や `{weekday}` の動的日付差し込み機能
   - 30日間クールダウン保護

5. **Threads 実機プレビュー & 実行コンソール**
   - Threads公式UIを忠実に再現したカードプレビュー
   - リアルタイム待機カウントダウンタイマー
   - 実行ログ / コンソール出力（`execution_log.txt`, `error_log.txt` 保存対応）

## セットアップ & 起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動 (ポート 3000)
npm run dev

# プロダクションビルド
npm run build
```
